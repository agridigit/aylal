# Tâches : F4 — Irrigation et bilan hydrique

**Branche** : `007-irrigation-water-balance` | **Entrées** : spec.md, plan.md, data-model.md, research.md, contracts/, quickstart.md, decisions.md
**Règle** : test first strict. Dans chaque bloc, les tests RED (unitaire `tests/unit/`, intégration `tests/integration/`, contrat `tests/contract/`, bout en bout `tests/e2e/` des services ou `apps/mobile/maestro/`) viennent AVANT l'implémentation, sont lancés via Docker (`make test-api`, `make test-mobile`, `make e2e`), DOIVENT échouer (commit `test(007-irrigation-water-balance): red - <sujet>`), puis GREEN (`feat(007-irrigation-water-balance): green - <sujet>`), puis REFACTOR (`refactor(...)`). Interdit de modifier un test pour le faire passer, sauf contradiction avec la spec, notée dans `decisions.md`.
**Notation** : `[P]` = fichiers différents, aucune dépendance en cours. `[USn]` = récit n de spec.md. Critères cités `Rn-Am` = récit n, scénario d'acceptation m ; `CL` = cas limite ; `G1`..`G9`, `G1b` = garde-fous de plan.md (`G<n>-RED` / `G<n>-GREEN`).
**Séparation** : les tâches **non-écran** (domaine, API, base, synchro, workers, view models) ne dépendent PAS de la porte design. Les tâches **`[écran]`** dépendent de **T004** (porte design) ET de la **fusion de `004-design-system` dans main** ; aucune ne démarre avant.
**Chemins** : API = `services/api/`, domaine = `packages/domain/`, mobile = `apps/mobile/`, workers = `services/workers/`. Tests : `services/api/tests/{unit,integration,contract,e2e}/`, `services/workers/tests/`, `packages/domain/tests/`, `apps/mobile/src/**/__tests__/`, `apps/mobile/maestro/`, `tests/platform/`.
**Interdits transverses** : aucune valeur agronomique (Kc, réserve utile, profondeur racinaire, salinité, méthode de pluie efficace) codée en dur ni semée par migration (fixtures de test seulement) ; aucun appel à `now()` / `Date.now()` / `current_date` dans le métier ; jamais de `FLUSHDB` ; aucun `DELETE` sur `operations`, `registry_entries`, `irrigation_events`, `water_analyses` (même en nettoyage de test) ; ne pas modifier `packages/ui`, `docs/design/*`, `specs/00[1-6]-*`.
